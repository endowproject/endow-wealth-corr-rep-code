# ENDOW Wealth Correlations — Replication Kit

This repository contains the analysis code for:

> **"Social Network Structure, Wealth, and Wealth Inequality Across Cultures"**
> The ENDOW Team

The study examines whether social capital measures derived from social network structure (support access, support provisioning, and average alter wealth) are correlated with wealth and wealth inequality across 40+ rural communities worldwide.

This repo provides code to generate all of the figures and tables, using faux data. With the use of faux data, the resulting tables/figures will not reproduce the actual figures/tables in the paper but instead fully show the code.

Installation of the relevant R packages should be straightforward and take a matter of minutes, though installation of tools related to the use of Stan may take a bit longer to set up, depending on your operating system and configuration. (This is necessary only for the running of the multilevel model).

With the faux data, the full script should take ~10 hours to run, largely thanks to the multilevel model (which will on its own take ~8 hours). Given this lengthy time, DerivedData already includes versions of the generated files.

## R Setup

The scripts find files using path variables that you define in your `.Rprofile`. See [this guide](https://stackoverflow.com/questions/46819684/how-to-access-and-edit-rprofile) if you are not familiar with `.Rprofile`.

Add the following to your `~/.Rprofile`, adjusting paths to match your machine, _or_ set them at the start of any session before executing 00_run_all.R:

**Mac:**
```r
EndowGitHub <- file.path("~", "Documents", "GitHub", "endow-wealth-corr-rep-code")
EndowDatabase <- file.path("~", "Documents", "GitHub", "endow-wealth-corr-rep-code", "endow-database-sim")
EndowDropbox <- file.path("~", "Dropbox", "ENDOW")
```

**Windows:**
```r
EndowGitHub <- file.path("C:/Users/tomru", "Dropbox (Personal)", "GitHub", "endow-wealth-corr-rep-code")
EndowDatabase <- file.path("C:/Users/tomru", "OneDrive - Stanford", "Documents", "GitHub", "endow-wealth-corr-rep-code", "endow-database-sim")
EndowDropbox <- file.path("C:/Users/tomru", "Dropbox (Personal)", "ENDOW")
```

After editing `.Rprofile`, restart R to pick up the changes. The replication kit will stop with a clear error message if any required variable is missing.

## Running the Replication Kit

Open a **fresh R session** and run:

```r
source("path/to/ENDOW-wealth-corr/00_run_all.R")
```

Or set your working directory first:

```r
setwd("~/Documents/GitHub/ENDOW-wealth-corr")
source("00_run_all.R")
```

### Skipping stages

If you only need to regenerate figures (not reprocess raw data), edit the flags at the top of `00_run_all.R`:

```r
SIMULATE_DATA          <- FALSE   # Skip database simulations
COMPILE_WEALTH         <- FALSE   # Skip Part A1
RUN_DATA_PROCESSING    <- FALSE   # Skip Part A2
RUN_DATASET_GENERATION <- FALSE   # Skip Part B
RUN_MODULARITY         <- FALSE   # Skip Part C
RUN_MULTILEVEL         <- FALSE   # Skip Part D
RUN_FIGURES            <- TRUE    # Run Part E only
SITES_TO_DROP          <- c("XX", "ZZ") # Drop sites we're not including
```

Parts C through E read from saved files in `DerivedData/`, so you can run them independently as long as those files exist.

## Pipeline Overview

### Part A1 - Compile Wealth Data

Takes possessions and valuation data from the `endow-database` repo and defines each sharing unit's aggregate wealth. Note that calls in the `su_wealth_compile.R` script to scripts not provided here for the actual ENDOW sites have been commented out.

| Script | What it does | Key outputs |
|--------|-------------|-------------|
| `su_wealth_compile.R` | Runs per-site wealth calculation scripts; compiles SU wealth tables; generates 50 ±20%-noised wealth datasets and (where needed) 50 MICE-imputed datasets | `su-wealth-output/*_SU_wealth.csv`, `noised_list.rds`, `imputation_list.rds` |

### Part A2 — Raw Data Processing

Takes survey data from the `endow-database` repo and builds network and metadata objects. Note that some lines in these scripts have been commented out, as they relate to site-specific exceptions for the actual ENDOW sites, and would result in errors if run here (where those sites do not exist).

| Script | What it does | Key outputs |
|--------|-------------|-------------|
| `process_data.R` | Cleans and standardizes survey variables; creates SU-level adjacency matrices for each survey prompt; calculates kinship matrices | `su_nets.rdata`, `su_meta.rdata`, `su_alters.rdata` |
| `analyse_data_and_create_networks.R` | Combines per-prompt networks into composite layers (loan, exchange, behav, info, main_supp); creates kinship networks; computes site-level network descriptives | `su_nets_expanded.rdata`, `igraphs_for_each_layer_list.rds`, `site_net_descriptives.csv` |

> **Important:** `process_data.R` should be run in a **fresh R session**. Running it after other packages have been loaded (especially packages that mask base functions) can cause errors with the `FamAgg` Bioconductor package.

### Part B — Dataset Generation

Transforms the network objects into analysis-ready datasets used by all figure scripts.

| Script | What it does | Key outputs |
|--------|-------------|-------------|
| `create_su_master.R` | Calculates network centrality (degree, betweenness, PageRank, Katz) for each SU across all network layers; merges with wealth data | `su_master.rds`, `su_master.csv` |
| `wealth_size_adjustment.R` | Regresses log(wealth) on log(SU size) within each site; saves size-adjusted residuals back into `su_master.rds` | Updates `su_master.rds` |
| `degree_size_adjustment.R` | Same for network degree | Updates `su_master.rds` |
| `country_vars.R` | Compiles country-level variables | `site_country_descriptives.csv` |
| `Economic_Connectedness_Revised.R` | Computes Economic Connectedness (EC) — fraction of a unit's network partners that are higher-wealth — and Individual EC (IEC) across multiple wealth normalisations and network layers | `IEC_Revised.csv`, `EC_Revised.csv`, `EC_Revised_Reshape.csv` |
| `site_level.R` | Computes site-level Gini coefficients, wealth quantiles, and summary statistics | `gini_site_data.csv` |
| `kinship.R` | Creates kinship variables | `sitelevel_kinship.csv` |
| `Modularity.R` | Calculates wealth modularity - takes hours to run! | `modularity_data_set_wealth.rds`, `modularity_data_set_wealth_per_capita.rds`|
| `merge_and_clean_data_for_lasso.R` | Merges all site-level datasets (network, Gini, EC, geospatial, WDI, HRAF ethnographic) into a single analysis file | `DataForLASSO.csv` |

### Part C — Modularity

| Script | What it does | Key outputs |
|--------|-------------|-------------|
| `Modularity.R` | Calculates Wealth Modularity | `modularity_data_set_wealth_per_capita.rds` |

Each script reads from `DerivedData/` and writes figures to `EndowDropbox/Figures/` or tables to `EndowDropbox/Tables/`.

| Script | What it produces |

| `wealth_sensitivity_forest_plots.R` | Wealth sensitivity forest plots: replicates the four main within-site avg-alter-wealth figures but replaces regression CIs with an empirical interval from the 50 noised datasets. Point = median correlation across trials; bar = [2nd, 49th] sorted values ≈ 96% empirical interval (`paper-1st-draft/within-site-multipanel-frank/noise_Sitewise_*.png`) |
| `kinship_analysis.R` | Kinship analysis: kin vs non-kin network comparisons, AAW–Gini mediation (`kinship/`) |
| `LASSO_and_Related_Analysis.R` | Main cross-site analysis: key scatter plots (Gini vs degree Gini, Frank, modularity), LASSO variable selection, hierarchical model, correlation plots, regression tables |
| `Economic_Connectedness_Quartiles_Correlations.R` | Heatmaps of EC between wealth quartile pairs vs Gini (`FRank-Quartiles/`, `RC-Quartiles/`) |
| `wealth_ratios_vs_gini.R` | 90/10 and 80/20 percentile wealth ratios vs Gini — robustness check (`ninety-ten/`) |
| `wealth_homophily.R` | Neighbour wealth standard deviation vs Gini (`wealth_homophily/`) |
| `assortativity.R` | RAAW vs Assortativity (`cross-site/`) |

## Key Data Files

All intermediate data files live in `DerivedData/` (inside this repo):

| File | Description |
|------|-------------|
| `su_master.rds` | The main node-level dataset. One row per sharing unit per network layer. Contains centrality measures (degree, betweenness, PageRank), wealth measures (absolute, per-capita, per-adult, size-adjusted), and their rank-transformed versions. |
| `su_nets_expanded.rdata` | List of igraph objects: one per site × network layer combination. |
| `su_meta.rdata` | SU-level metadata (household size, adult count, able-bodied count, etc.), aligned to network adjacency matrix order. |
| `su_alters.rdata` | Alter-level data for each SU, including external (out-of-community) alters. |
| `gini_site_data.csv` | Site-level Gini coefficients across multiple wealth normalisations, plus median/mean/max wealth. Frequently merged into other analyses. |
| `IEC_Revised.csv` | Individual-level EC for each SU × network layer, computed for multiple wealth normalisations (absolute, per-capita, per-adult, size-adjusted). |
| `EC_Revised.csv` | Site-level EC in long format. `EC_Revised_Reshape.csv` is the wide version (one column per layer). |
| `DataForLASSO.csv` | Merged site-level dataset: one row per site, containing Gini, EC, network structure measures, geospatial variables, WDI indicators, and ethnographic covariates. The main input for cross-site regressions. |
| `modularity_data_set_wealth_per_capita.rds` | Modularity scores per site. |

## Gotchas and Known Issues

**`process_data.R` needs a fresh R session.**
The `FamAgg` Bioconductor package is used for kinship calculations. If other packages have been loaded first, it can conflict and throw a cryptic error like `"Error: No match found."` Restarting R and sourcing `00_run_all.R` directly (without loading other packages first) fixes this.

**`FamAgg` installation.**
Install from Bioconductor, not CRAN:
```r
if (!require("BiocManager", quietly = TRUE)) install.packages("BiocManager")
BiocManager::install("FamAgg")
```
